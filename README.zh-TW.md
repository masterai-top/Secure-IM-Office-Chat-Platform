## 🧠 Project Overview


This is a secure enterprise instant messaging platform.

本專案是一套企業級加密即時通訊系統。


Supports:


- Team chat / 團隊聊天

- Private messaging / 私聊系統

- Multi-device sync / 多端同步

- Secure message storage / 安全存儲

- Message search / 訊息檢索


👉 Designed for enterprise communication

👉 面向企業辦公室通訊系統
