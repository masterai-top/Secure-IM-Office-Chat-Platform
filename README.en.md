This is a secure enterprise instant messaging platform.


Supports:


- Team chat
- Private messaging
- Multi-device sync
- Secure message storage
- Message search


👉 Designed for enterprise communication


## ✨ Core Features


This project is a **professional enterprise-grade instant messaging solution** that has been operating stably for 4–5 years, serving multiple companies.
| Key Features | Description |
| :--- | :--- |
| 🔒 **Multi-layer Encryption** | Encrypted data transmission; supports permanent deletion of chat history from the database |
| 👥 **Team Structure** | Supports hierarchical management across multiple companies, teams, and groups |
| 💬 **Topic-driven** | Discussions organized by topic; complete chat history preservation |
| 🔄 **Message Sync** | Real-time message synchronization across devices; supports full-text search |
| 🎥 **Audio/Video Calls** | Supports voice chats and video calls |
| 📱 **Cross-platform** | Windows PC, Web, Android, iOS |
